Tech Stack: Flutter, Dart, Groq AI API, Firebase Firestore, NETS QR API

Core Engineering: Engineered a cross-platform mobile UI in Flutter/Dart integrated with Firebase Firestore for real-time state management and data persistence.

Authentication and Monetization (Not fully functional tested through flutter wallet): Secured user onboarding with OAuth 2.0 (Google, Microsoft) and implemented NETS QR payment integration for premium feature monetization.

Additional Features: Integrated specialized Flutter packages (fl_chart, table_calendar) to visualize productivity metrics and deliver scheduling workflows. Groq AI chatbot was included in order to help fulfill any student needs and resolve any issue impeding their progress
